# Zencoder

> Zencoder is a cloud-based video and audio encoding (transcoding) platform, now part of Brightcove. Its v2 REST API submits encoding jobs, produces multiple simultaneous outputs (MP4, HLS, DASH, HEVC/H.265, VP9, 4K/UHD, HDR10), applies captions, watermarks, clips, thumbnails, DRM and encryption, and posts completion webhooks. Authentication is an API key sent in the Zencoder-Api-Key header (or api_key query param). Base URL: https://app.zencoder.com/api/v2.

## APIs

- [Zencoder API reference](https://zencoder.support.brightcove.com/references/reference.html): v2 REST API — Jobs, Inputs, Outputs, Accounts, Reports.

## Operations

- POST /jobs — Create an encoding job (createJob)
- GET /jobs — List jobs (getJobs, paginated page/per_page)
- GET /jobs/{job_id} — Get job details (getJob)
- GET /jobs/{job_id}/progress — Get job progress (getJobProgress)
- PUT /jobs/{job_id}/resubmit — Resubmit a job (resubmitJob)
- PUT /jobs/{job_id}/cancel — Cancel a job (cancelJob)
- GET /inputs/{input_id} — Get input details (getInputDetails)
- GET /outputs/{output_id} — Get output details (getOutputDetails)
- GET /account — Get account details (getAccountDetails)
- GET /reports/vod — Get usage report (getUsageReport)
- GET /reports/minutes — Get minutes used (getMinutesUsed)
